What pi-post Did

Wake-on-idle delivery: every clue started an idle suspect's next turn — no polling, no "check your messages." The suspects' briefs were their first turns; the Ghost's replies were every turn after.

Named sessions: each suspect was summoned with pi --name, so every delivery header read miss-scarlett, not N indistinguishable <dir>-<addr4> defaults from one run directory.

The queue: a retired suspect's session was closed mid-game; a clue sent to it reported queued and landed as the session's first turn on resume — the address names the conversation, not the process.

Process senders: dawn arrived by pi-post send from a plain shell timer, not from any pi session — anything that can run a command can message a session.

Peer-to-peer: whisper hour resolved fellow guests by session name, no hub required.

The authority boundary: every message arrived labeled as carrying no authority. The suspects lied, framed each other, and demanded things all night, and none of it could compel anything. The game only works because the channel is untrusted by design.

Mr. Boddy rests. The '87 is spoken for.
